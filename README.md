# TrueAncestor SELF Resigner v1.97

**TrueAncestor SELF Resigner** est un utilitaire Windows pour **PlayStation 3**, créé par **JjKkYu**. Il permet de déchiffrer et de re-signer certains fichiers exécutables de jeux PS3, notamment les fichiers `EBOOT.BIN`, `SELF` et `SPRX`.

**Version :** 1.97  
**Plateforme :** PS3  
**Développeur original :** JjKkYu

## Fonctionnalités

- Déchiffrement de fichiers exécutables PS3 pris en charge.
- Re-signature des fichiers `EBOOT.BIN`, `SELF` et `SPRX`.
- Préparation de fichiers pour les environnements PS3 compatibles.
- Traitement de plusieurs exécutables selon les options de l'outil.

## Nouveautés de la version 1.97

- Vérification des fichiers **RAP** avant certaines opérations sur `EBOOT.BIN`.
- Remplacement du moteur de recherche de clés par `klic_bruteforcer`.
- Ajout d'un fichier `klics.txt` actualisé.

## Utilisation

1. Téléchargez une copie de l'outil depuis une source autorisée et extrayez son archive sur votre PC Windows.
2. Conservez une sauvegarde du fichier PS3 original avant toute opération.
3. Lancez l'utilitaire et suivez les options proposées pour le type de fichier à traiter.
4. Vérifiez le résultat avant d'utiliser le fichier modifié dans un environnement compatible.

## Important

- Cet utilitaire est conçu pour la **PS3** : il ne prend pas en charge les exécutables PS4.
- Toutes les variantes de fichiers et de firmwares ne sont pas forcément compatibles.
- Une mauvaise modification ou une signature inadaptée peut empêcher un jeu de fonctionner.
- Ce dépôt n'est **pas le projet officiel** du développeur original.
